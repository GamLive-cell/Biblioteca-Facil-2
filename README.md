# Biblioteca Fácil

Sistema web para gerenciamento de uma biblioteca.

## Tecnologias
- Angular 21
- Node.js
- Express
- MongoDB

## Objetivo
Gerenciar livros, usuários, empréstimos e devoluções.

## Organização
- frontend/: aplicação Angular
- backend/: API e regras de negócio
- docs/: documentação do projeto
